## Phase sequence

1. Architecture and design foundation
2. Authentication, database, and user management
3. Public website and homepage
4. Opportunity discovery system
5. Writing services and digital agency
6. Learning platform and blog
7. Dashboards, AI, and admin panel
8. Optimization, security, deployment, and final polish

Each phase must preserve the contracts in these documents and add tests before the next phase begins.
